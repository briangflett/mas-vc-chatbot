# Strategic Planning Resource Library Guide

Source: MAS Resource Library (SharePoint)

Strategic Planning Resource Library

Purpose

The purpose of the Strategic Planning Resource Library is to enable VCs to share strategic planning tools and other resources. It is also a development tool – VCs can see other approaches to strategic planning.

Accessing and Using Resource Library Material

The resource files are grouped into appropriate folders.  The ‘owner’ of the document is noted on each document – this is the VC that contributed the material.

Unless otherwise indicated VCs can download and modify these files as required to satisfy their specific MAS client requirements.

The resource files themselves may be in the form of a presentation, tool, process, policy description/template or general information and advice on how to address a specific issue.

If you have questions about the use of particular tools or templates, you can contact the ‘owner’. 

Process for submitting and maintaining library material

To contribute resource material to the library VCs are requested to:

 Ensure the resource file is in a user-friendly format with a brief description of the use of the material. 

Email the file to Chris Govern at chris.govern@sympatico.ca who will arrange to have it posted.

Owners of resource files are encouraged to periodically review and update their material, as appropriate, using the above process. Any questions regarding the use of the Library should be directed to Chris Govern at chris.govern@sympatico.ca.
