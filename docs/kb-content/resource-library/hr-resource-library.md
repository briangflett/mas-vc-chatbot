# Human Resources and Coaching Resource Library Guide

Source: MAS Resource Library (SharePoint)

HR Resource Library

Purpose

The purpose of the HR Resource Library is to enable VCs to voluntarily share HR tools and solutions among themselves. The ability to exchange this kind of information can potentially save VCs considerable time and effort in developing original material on their own when successful approaches and solutions already exist.

Accessing and Using Resource Library Material

The HR Resource Library is accessed via the following link to our members’ private page on the MAS web site:http://masadvise.org/hr-resource-library/

From the member’s private page click on “HR VC Resource Library”. Under this category you will see a file that describes the purpose and instructions for using the library followed by a list of individual HR resource files that have been submitted by VCs.

The HR resource files are listed by major category such as Recruiting & Interviewing, Performance Management, Policies and Practices, Compensation, Succession Planning, etc

Unless indicated otherwise VCs can download and modify these files as required to satisfy their specific MAS client requirements.

The resource files themselves may be in the form of a presentation, tool, process, policy description/template or general information and advice on how to address a specific HR topic.

Each file contains a brief introductory page that provides owner contact information, a description of the material and how it might be used. VCs may contact the file owner directly if they have questions or wish to discuss the information in further detail.

Process for submitting and maintaining library material

To contribute resource material to the library VCs are requested to:

1. Ensure their resource file is in a user friendly format with a brief information page at the beginning of the file (including the file owner’s contact information and description of the material).

2. Email the file to Glenn Christie at: ggchristie@rogers.com who will arrange to have it posted in the HR Resource Library.
Owners of resource files are encouraged to periodically review and update their material, as appropriate, using the above process. Any questions regarding the use of the Library should be directed to Glenn Christie: ggchristie@rogers.com
