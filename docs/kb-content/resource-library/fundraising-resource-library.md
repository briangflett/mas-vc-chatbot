FUNDRAISING RESOURCE LIBRARY

Purpose

The purpose of the Fundraising Resource Library is to allow VCs to share tools and other resources. This can potentially save VCs considerable time and effort in developing original material when successful approaches already exist.

Accessing and Using Resource Library Material

The resource files are for use by any of the Fundraising VC’s. The ‘owner’ of the document is noted on each document – this is the VC that contributed the material.

Unless indicated otherwise, VCs can download and modify these files as required to satisfy their specific MAS client requirements.

The resource files themselves may be in the form of a presentation, tool, process, policy description/template or general information and advice on how to address a specific Fundraising topic.

VCs may contact the file owner directly if they have questions or wish to discuss the information in further detail.

Process for submitting and maintaining library material

To contribute resource material to the library VCs are requested to:

Ensure their resource file is in a user-friendly format with a brief description of the use of the material.

Email the file to Rita Daniel at rsdaniel@rogers.com who will arrange to have it posted in the Fundraising Resource Library.

Owners of resource files are encouraged to periodically review and update their material, as appropriate, using the above process. Any questions regarding the use of the Library should be directed to Rita Daniel at rsdaniel@rogers.com. Resource Library
