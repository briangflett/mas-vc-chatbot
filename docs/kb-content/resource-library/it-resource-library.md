IT Resource Library

Purpose

The purpose of the IT Resource Library is to enable VCs to share tools and templates for IT work. The majority of these documents fall into one of three categories

Free documents available on the web

Documents created for customers with customer name removed

A combination of the above (a template taken from the web and modified for client)

A number of the documents are from the Techsoup library (http://www.techsoupcanada.ca) and are free for use by non-profits.

Accessing and Using Resource Library Material

The resource files are grouped into appropriate folders.  The ‘owner’ of the document is noted on each document – this is the VC that contributed the material.

If no VC name is indicated the document is downloaded from the web

Unless otherwise indicated VCs can download and modify these files as required to satisfy their specific MAS client requirements.

The resource files themselves may be in the form of a presentation, tool, process, policy description/template or general information and advice on how to address a specific issue.

If you have questions about the use of particular tools or templates, you can contact the ‘owner’ or the IT Practice Experts. 

Process for submitting and maintaining library material

To contribute resource material to the library VCs are requested to:

Ensure the resource file is in a user-friendly format with a brief description of the use of the material. 

Remove any client names and replace with XXX.

Email the file to Sue Pulfer at spulfer@rogers.com who will arrange to have it posted.

Owners of resource files are encouraged to periodically review and update their material, as appropriate, using the above process. 

Any questions regarding the use of the Library should be directed to Sue Pulfer at spulfer@rogers.com.
